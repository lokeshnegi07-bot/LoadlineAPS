Loadline APS for Mac

Install
1. Unzip this folder (double-click the zip).
2. Double-click "Install Loadline.command".
   The first time, macOS may say it can't check the developer. Then open
   System Settings > Privacy & Security, scroll down and click "Open Anyway" next to Install Loadline,
   or right-click the file and choose Open.
3. Answer y or n to: add to the Dock, and start the Loadline server when you log in.

When it finishes, Loadline APS opens in its own window, and you get:
- Loadline APS in Applications (in your home folder), so it shows in Launchpad and Spotlight
- a Loadline APS shortcut on the Desktop, and in the Dock if you said yes

How it runs
- A small local web server hosts it on this Mac at http://localhost:8765 (only this Mac can open it).
- It opens in Google Chrome or Microsoft Edge as an app window (no tabs or address bar) if one is installed, otherwise in Safari.

Updates
- Each time you open Loadline it checks GitHub (lokeshnegi07-bot/LoadlineAPS, main branch) for a newer version
  and downloads it in the background. The new version shows the next time you open Loadline.
- Your data stays: it is kept in the browser, not in the program files.

Remove: double-click "Uninstall Loadline.command".
